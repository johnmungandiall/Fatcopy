# About the user

## Language and style
- Writes requests in Telugu mixed with English technical words, in roman script
  ("fast ga copy cheyadaniki oka windows software create chey usimg python").
  Short and outcome-focused: what to build, not how.
- Answer in the same register — romanized Telugu, plain words, short lines.
- Wants the thing BUILT, not discussed. No option menus before the work starts
  when the goal is already clear.

## Expectations observed
- **One deliverable, the whole thing.** "oka windows software" — one software,
  complete: a working way to start it and a built executable, not a library
  fragment or a demo.
- **Production level, not demo level.** Verify the work in the real
  implementation before claiming it is done; do not leave rough edges for the
  user to point out.
- **Do the work yourself.** Build the executable, run the tests, report results —
  never hand the user a command to run in their place.
- **Release is the user's call.** Building the artifacts is fine; publishing,
  tagging or deploying a version is not, unless asked.
